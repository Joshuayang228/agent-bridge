# 规则反馈

> AI 在执行过程中发现规则不合理、缺失或冲突时记录到此文件。
> 累计 **3 条**反馈后，AI 主动建议修订规则；用户确认后批量更新 CLAUDE.md。

## 格式

```
### #序号 - 简述

- **规则位置**：哪个 CLAUDE.md / 哪条规则
- **问题类型**：不合理 / 缺失 / 冲突 / 过于严格 / 过于宽松
- **场景描述**：什么情况下触发的
- **建议**：怎么改
- **状态**：待审视 / 已采纳 / 已驳回
```
